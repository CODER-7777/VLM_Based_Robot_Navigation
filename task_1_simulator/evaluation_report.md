*Notes on Evaluation Criteria:*
- **Environment library:** Which photoreal indoor/outdoor scenes already exist, and are they free/licensed for research?
- **Visual realism:** Ray tracing / PBR quality, sensor realism (RGB, depth, LiDAR), sim-to-real gap.
- **Quadruped support:** Existing robot models (ANYmal, Go2/Go1, Spot), contact/friction fidelity, available locomotion policies.
- **Performance:** FPS / real-time factor, GPU requirement, parallel envs for RL.
- **Setup effort:** Install difficulty, ROS/Python API, docs and community activity.
- **Licensing:** Open source vs paid, restrictions on academic use.
