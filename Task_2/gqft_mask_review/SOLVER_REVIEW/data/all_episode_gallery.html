Model provenance and diagnostic scope

Models are frozen. No scale, rotation or pose-based heading correction was fitted to improve their predictions. Leg views restart at each recorded leg. Full-episode views run continuously across leg boundaries. Every 24 flow pairs, the next chunk is placed using the model's own predicted heading. The first step of a chunk has only one pair of history. These plots are recorded-episode diagnostics, separate from the HSGM validation benchmark.
