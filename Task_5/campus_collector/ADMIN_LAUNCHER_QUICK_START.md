# Admin: start here

1. Connect to the approved IITK network. Extract this ZIP and open its launcher.
2. The website opens automatically. Sign in with your admin account; administration opens automatically.
3. **New account** → enter username → create. Share its login privately.
4. Select a person → tick their tasks → **Save assignment**.
5. To record your own samples, open **Collector** and follow RECORDING_STEPS.txt.
6. Finish uploads and save assignment changes before closing the dashboard. Closing its last tab exits the local launcher automatically.

After a crash, reopen and sign in again. Saved accounts, assignments and recordings remain on the server. A recovered assignment draft still needs review and **Save assignment**. Password fields are never backed up.

The same participant ZIP can be shared with everyone using that operating system. Send each person's login separately. Never share this admin ZIP, catalog exports or another person's login.
